# 🚀 Start Your Application

## First Time Setup

```bash
# 1. Setup backend
cd backend
pip install -r requirements.txt
python save_model_locally.py

# 2. Setup frontend
cd ../frontend
npm install
```

## Run Application

### Terminal 1 - Backend
```bash
cd backend
python run.py
```
✅ Backend: http://localhost:8000

### Terminal 2 - Frontend
```bash
cd frontend
npm run dev
```
✅ Frontend: http://localhost:5173

---

**That's it! Open http://localhost:5173 and start detecting emotions! 🎭**
